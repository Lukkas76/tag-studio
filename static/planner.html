Do KPI ao plano mínimo de tagueamento

Envie as telas da jornada e a pergunta de negócio. O Planner indica o que taguear (e o que não), monta o plano mínimo de mensuração e marca os elementos na imagem.

Também dá para colar um print com Ctrl+V. PNG, JPG, WEBP ou GIF · até 6 telas

Link de um frame (com node-id) entra direto. Link do arquivo ou de uma página mostra os frames para você escolher.

Sem cota na API do Figma? No Figma, selecione o frame e use Ctrl+Shift+C (copiar como PNG); depois volte à aba “Enviar imagem” e cole com Ctrl+V.

Usar meu token do Figma (opcional)

O servidor não tem um token do Figma configurado: para buscar pela URL, informe o seu.

Necessário quando o servidor não tem token ou não tem acesso ao arquivo. Gere em Figma › Settings › Security › Personal access tokens, com o escopo “File content: Read only”; ele expira em no máximo 90 dias. Salvo só neste navegador.
